## 内容

### 为什么从类型出发

游戏类型（genre）不是按美术风格或故事背景划分，而是按**玩家与游戏的交互方式**划分：第一人称射击无论发生在科幻还是军事题材里，本质仍是 FPS。选定类型，几乎决定了后面的一切——核心机制、所需资产量、技术栈、目标受众，以及最关键的：**独立团队能否在人力、预算、工期内把它做出来并卖出去**。

独立开发者的硬约束通常很清晰：人数少（常是 1–5 人）、预算有限、工期以年计、发行与获客高度依赖社区口碑而非买量。因此立项前先理解品类版图、再评估"我能不能做、值不值得做"，比凭感觉冲进一个热门品类更重要。本文先给出尽量全面的类型—子分类地图，再从独立开发者视角拆解决策。

### 市场主流游戏类型与子分类

> 以下大类参考 Newzoo 游戏分类法与 Wikipedia 类型词条整理，子分类按市场常见用法补充。

#### 动作类 (Action)

以身体协调、反应与操作挑战为核心，是所有类型中最庞大的根类。

- **平台跳跃 (Platformer)**：以跳跃、攀爬穿越关卡，含横向卷轴与精准操控；代表《超级马里奥》《Celeste》《空洞骑士》。
- **清版动作 / 砍杀 (Beat 'em up / Hack & Slash)**：横版推进、群敌近战；代表《双截龙》《鬼泣》《战神》。
- **射击 (Shooter)**：见下文"射击类"独立成类。
- **潜行 (Stealth)**：规避侦测完成目标；代表《合金装备》《Hitman》。
- **动作 Roguelike**：动作操作 +  Roguelike 死亡重开；代表《死亡细胞》《哈迪斯》。
- **硬核动作 (Hardcore Action)**：高难度连招与 boss 战；代表《只狼》《艾尔登法环》类魂。

#### 角色扮演类 (RPG)

以角色成长、数值养成与剧情推进为核心。

- **日式 RPG (JRPG)**：回合制/指令制、强叙事；代表《最终幻想》《Persona》。
- **欧美 CRPG / WRPG**：玩家选择驱动、开放探索；代表《博德之门3》《巫师3》《辐射》。
- **动作 RPG (ARPG)**：实时动作操控 + 养成；代表《暗黑破坏神》《原神》。
- **回合制 RPG**：纯回合战斗；代表《三角战略》《神领编年史》。
- **策略角色扮演 (SRPG / 战棋)**：战棋布局 + 养成；代表《火焰之纹章》《铃兰之剑》。
- **大型多人在线 RPG (MMORPG)**：长线成长 + 社交；代表《魔兽世界》《最终幻想14》。
- **卡牌战斗 RPG (Collectible Battle RPG)**：收集 + 养成；代表《剑与远征》《召唤物语》。

#### 策略类 (Strategy)

以规划、资源管理与战术决策为核心。

- **即时战略 (RTS)**：实时调度资源与军队；代表《星际争霸》《帝国时代》。
- **回合制策略 (TBS)**：轮流行动；代表《文明》《XCOM》。
- **战棋 (Tactics)**：网格上的回合博弈，常与 RPG 融合。
- **塔防 (Tower Defense)**：抵御波次敌人；代表《植物大战僵尸》《Bloons TD》。
- **MOBA**：多人在线战术竞技；代表《英雄联盟》《DOTA2》。
- **4X**：探索、扩张、开发、征服；代表《群星》《文明》的宏观层。

#### 模拟类 (Simulation)

复现现实或拟真系统的体验。

- **生活模拟 (Life Sim)**：经营角色人生；代表《模拟人生》《动物森友会》。
- **经营 / 建造 (Tycoon / City-Building)**：建城市、公司、经济体；代表《模拟城市》《城市：天际线》《过山车大亨》。
- **载具模拟 (Vehicle Sim)**：飞行、驾驶拟真；代表《微软飞行模拟》《欧洲卡车》。
- **沙盒生存 (Sandbox Survival)**：代码生成世界 + 采集建造；代表《我的世界》《泰拉瑞亚》《英灵神殿》。

#### 冒险与解谜 (Adventure & Puzzle)

重叙事、探索与解题，而非操作强度。

- **点击冒险 (Point-and-Click)**：鼠标解谜推进；代表《猴岛小英雄》。
- **叙事冒险 / 互动剧情**：分支选择驱动；代表《底特律》《隐迹渐现》。
- **视觉小说 (Visual Novel)**：对话与选项主导；代表《Doki Doki》《逆转裁判》。
- **步行模拟 (Walking Sim)**：氛围与叙事；代表《Firewatch》《旅程》。
- **生存恐怖 (Survival Horror)**：资源稀缺 + 惊悚；代表《生化危机》《_signalis》。
- **解谜 (Puzzle)**：见下。

#### 解谜类 (Puzzle)

以逻辑、空间或规则解题为核心。

- **三消 (Match-3)**：图案匹配；代表《Candy Crush》《宝石迷阵》。
- **物理解谜**：物理规则驱动；代表《愤怒的小鸟》《Portal》。
- **文字 / 密室逃脱**：线索推理；代表《The Room》《锈湖》。
- **益智问答 / 脑力**：字谜数独；代表《Wordle》《Brain Age》。
- **合成与放置 (Merge / Idle)**：合成进化或离线产出；代表《合并村庄》类、《放置勇者》。

#### 射击类 (Shooter)

以远程武器、距离交战为核心，可按视角与模式细分。

- **第一人称射击 (FPS)**：拟真枪法 + 战术；代表《CS2》《使命召唤》《光环》。
- **第三人称射击 (TPS)**：兼顾动作表现；代表《战争机器》《控制》。
- **弹幕射击 (Shoot 'em up)**：飞行载具对抗弹幕；代表《东方》系列。
- **英雄射击 (Hero Shooter)**：预设英雄 + 团队配合；代表《守望先锋》《Apex》。
- **刷宝射击 (Looter Shooter)**：射击 + 装备养成 + 随机掉落；代表《命运2》《全境封锁》。
- **大逃杀 (Battle Royale)**：最后存活；代表《PUBG》《堡垒之夜》。
- **多人在线射击 (MMOFPS)**：大规模联网对抗；代表《穿越火线》《行星边际2》。

#### 平台与 Roguelike

（动作类已覆盖平台跳跃，这里聚焦"死亡重开 + 程序生成"谱系。）

- **类银河战士 (Metroidvania)**：探索 + 能力解锁；代表《奥日》《空洞骑士》。
- **Roguelite / Roguelike**：关卡程序生成、死亡重开、build 构筑；代表《以撒的结合》《哈迪斯》《死亡细胞》。
- **肉鸽卡牌 (Roguelike Deckbuilder)**：卡牌构筑 + 肉鸽；代表《杀戮尖塔》《怪物火车》。

#### 卡牌与棋类

- **构筑卡牌 (Deck-builder)**：自建牌组取胜；代表《杀戮尖塔》。
- **集换式 (CCG)**：收集卡牌对战；代表《炉石传说》。
- **自走棋 (Auto-battler)**：布阵自动战斗；代表《云顶之弈》《刀塔自走棋》。

#### 竞速、体育与音乐

- **竞速 (Racing)**：街机竞速（《马里奥赛车》）、模拟竞速（《GT 赛车》《极限竞速》）、卡丁车。
- **体育 (Sports)**：传统体育（《FIFA》《NBA 2K》）、街机/幻想体育（《火箭联盟》）。
- **音乐节奏 (Rhythm)**：节拍操作；代表《Cytus》《节奏大师》《Just Dance》。

#### 休闲、社交与其他

- **超休闲 (Hyper-casual)**：极简玩法、广告变现；细分动作/模拟/益智/ASMR/多人对抗。
- **派对游戏 (Party)**：多人同屏乱斗；代表《猛兽派对》《胡闹厨房》。
- **舒适游戏 (Cozy)**：轻松治愈、低冲突；代表《星露谷物语》《Unpacking》。
- **社交推理 (Social Deduction)**：阵营对抗；代表《Among Us》《鹅鸭杀》。
- **MMO / 大型多人在线**：持续运营的世界；常与 RPG、沙盒融合。

### 独立开发者的适配性评估

首先排除掉某TGA年度最佳的制作团队，独立开发者（或者是独立团队）通常不具备大量资金用于外包，所以应将入门作聚焦于游戏性以及内容创新性上（例如 [【独立游戏开发】赛博排球 v0.10](https://www.bilibili.com/video/BV1fiqfBpENU) 这类小团队开发日志，展示了从玩法原型到可玩版本的真实迭代）。

#### 适合独立开发的方向（及原因）

- **解谜 / 益智**：几乎不依赖高质量美术与音频，靠逻辑与关卡设计取胜；原型易验证、单人可做（《Portal》《The Room》式成功验证了这一点）。
- **平台跳跃 / 精准平台**：主流引擎（Godot/Unity）对平台物理有原生支持；核心循环强、速通社区带来天然传播；《Celeste》是标杆。
- **Roguelike / 肉鸽**：程序生成让"内容消耗速度"与"内容生产成本"脱钩，重玩性高、口碑驱动传播——近年最成功的独立品类之一。
- **塔防 (Tower Defense)**：系统/数值驱动，美术门槛低，且与 Roguelike 融合（肉鸽塔防）空间大，非常适合独立团队。
- **叙事冒险 / 视觉小说**：重写作、美术；直播与二创传播性强；蓝海社区（如女性向舒适冒险）仍有空白。
- **卡牌构筑 / 自走棋**：系统驱动、内容可由规则生成，扩展成本低。

#### 需要谨慎或不太适合的方向（及原因）

- **3A 级开放世界动作 RPG**：没钱，没技术，没人手，这辈子能做完就烧高香了。
- **写实 / 军事射击**：暂且不提品牌垄断（《COD》《战地》系列），写实资产昂贵，且多人部分强依赖联网后端与反作弊，小团队难以支撑。
- **MMORPG / 大型多人在线**：联网架构、经济系统、海量长线内容，技术栈与运营成本双高。
- **体育模拟**：授权壁垒（《FIFA》《NBA 2K》）与拟真资产门槛，独立几乎无法正面竞争。
- **RTS**：AI 寻路、大规模平衡极难，对初学者不友好，最重要的是RTS没落了，极高的学习成本和高强度技术对抗的单挑竞技导致RTS在现在的市场很难有新鲜血液注入，但社区活跃度很高，且玩家粘性大，运营跟上的话很难暴毙。
- **CRPG**：《博德之门3》把品类预期与系统复杂度同时拉满，开发成本远超多数独立融资能力（多位开发者公开反馈"RPG 市场现在很糟糕"）。
- **超休闲（纯广告变现）**：微信小游戏，但人家的游戏都是同一个套路换个美术就能再赚一次（关卡和数值都不变的那种），且用户粘性低，无法长期换皮更新容易入不敷出。

#### 评估维度与判断方法

立项前用以下维度给品类打分，而非凭热度：

1. **内容产出成本 vs 消耗速度**：能否用程序生成/系统规则摊薄内容生产？（Roguelike、卡牌、沙盒占优）
2. **美术与音频门槛**：是否可用极简、像素、程序化或风格化替代而不损体验？（解谜、平台、叙事占优）
3. **是否强依赖联网 / 运营 / 反作弊**：越多后端依赖，独立风险越高（MMO、竞技 shooter 慎入）
4. **市场竞争与差异化空间**：红海（开放世界 ARPG、体育）难突围；蓝海与"被 AAA 放弃的品类"（城市建造、JRPG、点击冒险）机会更大
5. **原型可验证性与核心循环强度**：能否用 1–2 周做出可玩原型验证"好不好玩"？（平台、解谜、Roguelike 极易）
6. **平台与受众匹配**：Steam 最普适（但有100刀上架门槛）；itch.io 适合实验/ jam；移动端TapTap有独立分区曝光适合练手

> 补充：独立游戏失败的主因通常不是质量，而是**可发现性（获客）**。范围蔓延（scope creep）、忽略愿望单、跳过试玩 demo、定价过低，都是常见坑。

### 小结

独立开发者的选型原则可以浓缩为一句话：**选"范围可控、核心循环强、能用程序化或极简美术替代、社区传播性强"的方向，避开高质量资产和大型运营成本的强依赖，从核心玩法独特和短时上头来快速增加曝光度切入。**

最稳妥的起步组合通常是：2D + 强核心循环（平台跳跃 / 解谜 / Roguelike / 卡牌构筑）+ 风格化美术 + 早做可玩原型 + 提前建社区（Steam 愿望单、Discord）。先在小品类把"做出来并卖出去"跑通，再谈野心。
